#### 🎲 Featured project

**[Snakes and Ladders: OOP Mini-Game Edition](https://github.com/tahasaya04/Object-Oriented-Programming-Final-Project)**
A pixel-art Snakes and Ladders game built with C++17 and SFML 3. It has randomised boards, 2–4 players, three difficulty levels, and four minigames that decide whether you climb a ladder or slide down a snake. The game logic is kept separate from the SFML frontend, and the minigames share an abstract base class.
